# 07. 취약점 재현조건

> 2026-09-11 개정: 이 문서의 V01~V10은 이전 호환 동작이다. 새 버전은 [보안 제어 설계](14-security-controls.md)와 [S01~S16 실습](15-security-controls-practice.md)을 따른다. **새 S는 ON=방어 적용, OFF=방어 해제**이며 이전 V와 방향이 반대다. 이번 변경은 로컬 구현·검증까지 완료했고 Vultr에는 배포하지 않았다.

공통: 통제된 로컬/외부 인증 실습환경과 합성 데이터만 사용한다. 시스템 관리자가 해당 스위치 하나만 ON으로 설정한다. 웹 UI에는 공격 payload나 단계별 공격 튜토리얼을 제공하지 않는다.

| ID | 필요한 역할·데이터 | 설정 | 성공 판정 | OFF 비교 |
|---|---|---|---|---|
| V01 | 권한 없는 로그인 사용자와 타 부서/기밀 훈련 문서 | V01만 ON | 권한 없는 문서의 제목·설명 표시 | 객체 접근권한 검사로 차단/안전 처리 |
| V02 | 권한 없는 로그인 사용자와 Marker 포함 문서 | V02만 ON | 다운로드한 파일 내부 Marker 획득 | 다운로드 독립 인가로 차단/안전 처리 |
| V03 | 일반 직원 로그인 | V03만 ON | 일반 직원이 합성 관리자 보고서 열람 | 시스템 관리자 역할 검사로 차단/안전 처리 |
| V04 | 문서 접근권한과 유효한 로그인 세션 | V04만 ON | CSRF 토큰 없는 cross-site 요청의 상태 변경 | Laravel 13 origin/token 검증로 차단/안전 처리 |
| V05 | 로그인 사용자와 training-files public/restricted fixture | V05만 ON | restricted 훈련 Marker 파일 획득 | public canonical 경로 경계로 차단/안전 처리 |
| V06 | 로그인 사용자와 별도 합성 DB, SELECT 전용 계정 | V06만 ON | restricted 합성 검색 자료 표시 | 파라미터 바인딩로 차단/안전 처리 |
| V07 | 수정 가능한 훈련 문서와 이를 볼 수 있는 두 사용자 | V07만 ON | 다른 사용자 브라우저의 무해한 marker 스크립트 실행 | Blade escaping로 차단/안전 처리 |
| V08 | 로그인 사용자와 비실행 훈련 파일 | V08만 ON | 허용되지 않은 파일의 저장·attachment 다운로드 | 파일 유형·MIME·확장자 검사로 차단/안전 처리 |
| V09 | 합성 로컬 계정과 같은 IP | V09만 ON | 같은 조건의 반복 로그인 요청이 제한 없이 처리 | 이메일+IP 기준 5회/60초 제한로 차단/안전 처리 |
| V10 | 합성 계정과 로그인 전후 비교 세션 | V10만 ON | 로그인 전 쿠키 재사용 시 인증 상태 접근 | 로그인 SessionGuard 회전로 차단/안전 처리 |

HTTP 판정, 실제 파일 Marker, 브라우저 실행 Marker, 세션 쿠키 재사용을 구분한다. 특정 내부 동작을 확인하지 않은 결과는 성공으로 간주하지 않는다.
