## 2026-09-11 보안 ON·OFF 후속 승인

사용자 요청: 기능을 유지하면서 보안을 항목별로 ON/OFF하고 전체 프리셋을 제공한다. S01~S16의 정확한 범위는 [14-security-controls.md](14-security-controls.md)에 정의했다. ON은 방어 적용, OFF는 해제다. 전체 OFF는 정의된 16개 앱 방어 해제이며 유지되는 기능·파일 저장소 경계·외부 인프라는 해당 문서에 명시했다. 원본 RULE은 변경하지 않았다.

사용자 의도에 따라 로그인 필수를 해제해도 문서 작성자·공유·즐겨찾기·감사 관계를 유지하도록 세션별 익명 실습 계정을 제공한다. 로그인 필수를 다시 켜면 익명 요청은 즉시 차단되며 데이터는 유지한다. 기존 V 설정의 범위를 자동으로 확대하지 않도록 마이그레이션에서 값을 보존하고, 새 S 설정을 저장할 때 V를 모두 해제한다.

격리된 새 로컬 Compose 스택에서 자동 40개/954 assertions와 브라우저 4개 검증을 통과했다. 기존 preview 재생성은 자동 승인 검토에서 거절되어 새 프로젝트·볼륨으로 검증했다. 사용자 지시에 따라 이번 변경은 커밋/푸시 준비까지만 수행하고 서버 전송·공개 배포는 수행하지 않았다.
