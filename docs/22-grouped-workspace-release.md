## 사용과 복구

이미 열어 둔 탭은 한 번 새로고침하면 새 화면을 사용한다. 주소는 직접 링크와 탐색 이력을 위해 바뀌지만 같은 업무공간 안에서는 전체 문서를 다시 불러오지 않는다.

복구 시 이전 이미지 `intravault-prod-app:before-f12ed1e`를 `intravault-prod-app:latest`로 태그하고 동일 Compose 파일로 앱만 교체한다. 이어 `optimize:clear`, `view:cache`, `up`을 실행한다. 다음 빌드까지 이전 소스로 되돌려야 하면 위 백업의 소스도 별도 복구한다. DB와 파일 볼륨을 초기화하지 않는다.

검증 문서 후속 커밋과 실행 커밋은 구분한다. 서버 `.setup/deployed-commit.txt`는 이 문서 상단의 실행 커밋을 가리킨다. 실제 NAS와 다른 브라우저 엔진은 이번 배포에서 검증하지 않았다.
