IntraVault — CentOS Stream 9 설치 및 실행
사용자: root
프로젝트: /root/다운로드/IntraVault-native
접속 주소: http://192.168.10.111:18080

※ 이미 설치 완료했으면 맨 아래 “다음부터 실행”만 사용.
※ 비밀번호 편집이 필요하므로 설치 명령 전체를 터미널에 한꺼번에 실행하지 않기.
※ 오류가 나오면 해당 단계에서 중단.


1. 설치 저장소 추가

dnf install -y dnf-plugins-core
dnf config-manager --set-enabled crb
dnf install -y epel-release
dnf install -y https://rpms.remirepo.net/enterprise/remi-release-9.rpm


2. PHP 8.4 및 필요한 프로그램 설치

dnf module switch-to -y php:remi-8.4/common
dnf install -y php-cli php-mysqlnd php-mbstring php-xml php-curl php-zip php-intl php-gd composer mariadb-server unzip git


3. MariaDB 시작 및 설치 확인

systemctl enable --now mariadb
php -v
composer --version
mariadb --version
systemctl is-active mariadb


4. 압축 해제 및 프로젝트 폴더 이동

ZIP을 /root/다운로드 폴더에 넣은 뒤 실행.
이미 압축을 풀었다면 unzip은 생략.

cd /root/다운로드
unzip IntraVault-native.zip
cd IntraVault-native


5. 환경설정 파일 생성 및 편집

cp -n .env.example .env
nano .env

아래 두 항목의 값을 서로 다른 긴 영문·숫자 비밀번호로 변경:

DB_PASSWORD=네가정한비밀번호
LAB_DB_PASSWORD=별도로정한비밀번호

저장: Ctrl+O → Enter
종료: Ctrl+X


6. DB 생성 파일 비밀번호 편집

nano native/database.sql

다음 문자열을 교체. 작은따옴표는 유지:

replace-with-random-password → DB_PASSWORD와 같은 값
replace-with-reader-password → LAB_DB_PASSWORD와 같은 값

저장: Ctrl+O → Enter
종료: Ctrl+X


7. DB와 계정 생성 — 최초 한 번만 실행

mariadb --protocol=socket < native/database.sql

생성 확인:

mariadb --protocol=socket -e "SHOW DATABASES LIKE 'intravault_vmware%';"

다음 두 DB가 표시되면 정상:

intravault_vmware
intravault_vmware_lab


8. 파일 권한 및 저장 폴더 준비

chmod 600 .env native/database.sql
mkdir -p storage/app/private storage/framework/{sessions,views,cache/data} storage/logs bootstrap/cache


9. 라이브러리 설치

COMPOSER_ALLOW_SUPERUSER=1 composer install --no-interaction --prefer-dist --optimize-autoloader


10. 앱 초기화 및 관리자 생성

아래 명령을 한 줄씩 실행.
key:generate는 최초 설치 때만 실행.

php artisan config:clear
php native/check-local.php
php artisan key:generate
php artisan migrate --seed
php artisan intravault:create-admin

관리자 이름, 이메일, 사번, 부서명, 부서 코드, 비밀번호 입력.
비밀번호는 12자 이상.
비밀번호 입력 중 화면에 표시되지 않을 수 있음.


11. CentOS 내부 접속용 실행

bash native/start.sh

CentOS 브라우저:
http://localhost:18080

종료:
Ctrl+C


12. Windows에서 CentOS IP로 접속하도록 실행

기존 서버를 Ctrl+C로 종료한 뒤 실행:

PHP_INI_SCAN_DIR=":$PWD/native" php artisan serve --host=0.0.0.0 --port=18080

Windows 브라우저:
http://192.168.10.111:18080

관리자 이메일과 비밀번호로 로그인.
실행 터미널 유지.
종료는 Ctrl+C.


========== 다음부터 실행 ==========

systemctl start mariadb
cd /root/다운로드/IntraVault-native
PHP_INI_SCAN_DIR=":$PWD/native" php artisan serve --host=0.0.0.0 --port=18080

접속:
http://192.168.10.111:18080

VM IP가 바뀌면 접속 주소도 변경.
DB 생성과 앱 키 생성은 반복하지 않음.
